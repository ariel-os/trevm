Trevm example
=============

This example is to be use by the TREVM project to replance https://github.com/ariel-os/trevm/blob/main/examples/sure-vm/suit-updatable/suit/manifest.json

# The file: vars-trevm.json

The file [vars-trevm.json](./vars-trevm.json) shall be generated by the build system to include the correct values necessary for the final manifest. Tha values in the file are just placeholders to be used as an example to try the generation of the manifest


# The file: manifest-trevm.jinja

This the the jinja template to be used together with the vars.trevm.json.
This file is rendered using minijinja and the output file is a json file similar to the [manifest-trevm.json](manifest-trevm.json)

# Generating the cbor manifest

The commands calls taylor to generate the cbor manifest:

## Without signature

```sh
cargo run -- --template ./templates/trevm/manifest-trevm.jinja --vars-file ./templates/trevm/vars-trevm.json -o out
```

## With signature

```sh
cargo run -- --template ./templates/trevm/manifest-trevm.jinja --vars-file ./templates/trevm/vars-trevm.json -o out -k keys/demo-private-key.pem
```
